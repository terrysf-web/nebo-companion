# Nebo Companion

Nebo에서 인식한 손글씨를 공유받아 일정, 할 일과 알림으로 분류하고 실행 가능한 계획으로 저장하는 Android 동반 앱입니다.

## 사용 흐름

1. Nebo에서 날짜와 시간이 들어 있는 메모를 선택합니다.
2. **공유** → **Nebo Companion**을 선택합니다.
3. 앱에서 일정·할 일·알림으로 분류된 결과를 확인합니다.
4. **모든 항목 저장**을 눌러 일정은 Google Calendar에, 할 일은 앱에, 알림은 기기에 저장합니다.

TCL의 공유 목록에 Companion이 표시되지 않으면 Nebo의 **Sharing text** 화면 오른쪽 복사 아이콘을 누른 다음 Companion을 열고 **Nebo에서 복사한 텍스트 가져오기**를 누릅니다. 같은 분류·저장 과정이 실행됩니다.

지원 예시:

- `내일 오후 3시 팀 회의`
- `7월 20일 오전 10시 치과`
- `2026-07-21 14:30 프로젝트 검토`
- `Friday at 2 PM weekly review`
- `7월 20일 오후 3시 병원 예약, 1시간 전에 알려줘`

날짜와 시간이 둘 다 있어야 일정으로 인식합니다. 연도가 없고 해당 날짜가 이미 지났다면 다음 해로 해석합니다. 일정 길이는 우선 1시간입니다. `10분 전`, `1시간 전`, `하루 전` 같은 표현을 인식하며, 표현이 없으면 30분 전 알림을 사용합니다.

## 모닝 브리핑과 함께 쓰기

`morning-nas/` 폴더의 브리핑 서비스가 매일 아침 그날 브리핑을 `<날짜>.txt`로 만들어
Nextcloud에 올립니다. 아침 흐름은 이렇습니다.

1. Companion에서 **오늘 브리핑 열기**를 누릅니다. 처음 한 번만 브리핑이 동기화되는
   폴더(기본값 `Morning/briefs`)를 고르면, 다음부터는 그 폴더에서 오늘 날짜 파일을
   바로 읽습니다. 하위 폴더는 뒤지지 않으니 브리핑이 실제로 들어오는 폴더를 고르세요.
   (폴더를 바꾸려면 버튼을 길게 누릅니다.)
2. 브리핑을 읽고, Nebo에 붙여넣어 구분선(`---`) 아래에 그날 계획을 손으로 씁니다.
3. Nebo에서 텍스트로 변환해 Companion에 공유하면 일정·할 일·알림으로 저장됩니다.

구분선 위의 참고 내용(오늘 일정, 안 읽은 메일 등)은 이미 캘린더에 있으므로 저장하지
않습니다. 아래에 쓴 것만 분류합니다. 시간 눈금으로 넣은 `06`, `07` 같은 숫자만 있는
줄도 건너뜁니다. 구분선이 없으면 예전처럼 모든 줄을 읽습니다.

텍스트 파일 공유도 받습니다. Nextcloud나 파일 앱에서 `.txt`를 Companion으로 공유하면
그대로 읽어들입니다(예전에는 이미지로 간주해 OCR을 시도하다 실패했습니다).

폴더 접근은 사용자가 직접 고른 폴더에만 적용되며, 앱은 여전히 인터넷 권한을 요청하지
않습니다.

## GitHub에서 APK 만들기

`main` 또는 `claude/*` 브랜치에 커밋하면 **Actions → Build Android APK**가 자동 실행됩니다.
수동 실행은 **Actions → Build Android APK → Run workflow**입니다.

완료되면 두 곳에 APK가 올라갑니다.

- **Releases** — `nebo-companion-<버전>-build<번호>.apk` 파일이 그대로 붙습니다.
  태블릿에서 이 페이지를 열고 파일을 누르면 바로 설치됩니다. (처음 한 번은
  “이 출처의 앱 설치 허용”을 켜야 합니다.)
- **Artifacts** — 같은 파일의 zip. GitHub 로그인이 필요하고 압축을 풀어야 하므로
  PC에서 받을 때만 편합니다.

## 로컬 빌드

JDK 17과 Gradle 8.7이 설치된 환경에서:

```bash
gradle testDebugUnitTest assembleDebug
```

APK 경로: `app/build/outputs/apk/debug/app-debug.apk`

## 개인정보

이 앱은 인터넷 권한을 요청하지 않습니다. 공유받은 텍스트와 직접 고른 폴더의 브리핑 파일은 기기 안에서만 해석합니다. 일정과 리마인더를 저장하기 위해 Android 캘린더 읽기/쓰기 권한을 한 번 요청하며, 기본 Google Calendar가 있으면 그 캘린더를 우선 사용합니다.
